# 📷 Through My Frames

> **"Every frame tells a story, and this is mine."**  
> *A visual photography journal and portfolio by Ayush Mishra.*

---

## 🌟 Overview

**Through My Frames** is a curated photography portfolio and storytelling journal. Built with clean, vanilla web technologies, it showcases moments frozen in time—from architectural heritage and street life to tranquil sunsets, celestial skies, and intimate portraits across India.

---

## ✨ Features

- 🖼️ **Dynamic Photography Gallery**: 30+ frames rendered dynamically via JavaScript with responsive grid layouts.
- 🔍 **Interactive Lightbox Modal**: Click any photo to view it in high resolution with smooth previous/next navigation and keyboard support (`Esc`, `ArrowLeft`, `ArrowRight`).
- 🌓 **Dark / Light Theme Toggle**: Seamless theme switching with user preference saved in `localStorage`.
- 📖 **Dedicated Story Frames**: Immersive spotlight pages for special moments:
  - 📍 *Taj Mahal (Agra)* — Timeless wonder & silence
  - 📍 *Vrindavan* — Peace and spirituality
  - 🌙 *The Beautiful Moon* — Stillness of the night
  - 🌅 *Sunset & Sky* — Reflections, transitions, and dreams
  - 👤 *Meet the Photographer* — Ayush's vision and journey
- 📱 **Fully Responsive**: Optimized for seamless viewing across smartphones, tablets, and desktop displays without external UI frameworks.

---

## 🛠️ Tech Stack

- **Markup**: HTML5 (Semantic structure, accessibility)
- **Styling**: Modern CSS3 (Flexbox, CSS Grid, Custom Properties / CSS Variables, Media Queries)
- **Scripting**: Vanilla JavaScript (ES6+, Dynamic DOM rendering, Lightbox controller, Event handling)

## 🚀 Getting Started

No build steps or package managers required. Simply:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ayush110109mishra/Through-My-Frames.git
   ```
2. **Open in browser**:
   - Double-click `index.html` or open with VS Code Live Server / any local static HTTP server.
